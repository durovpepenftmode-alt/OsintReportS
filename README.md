# OSINT Report Studio v3

Локальный браузерный редактор для подготовки OSINT-отчётов.

## Запуск
Откройте `index.html` в браузере или запустите:
```bash
python -m http.server 8000
```
Затем перейдите на `http://localhost:8000`.

## В этой версии
- тёмная рабочая тема по умолчанию и переключение на светлую;
- отдельный режим «С нуля»: заполните сведения, затем создайте черновик отчёта;
- перемещение объектов перетаскиванием;
- ручка изменения размера и ручка вращения;
- дополнительные шрифты и параметры текста;
- цвет фона страницы, фоновое изображение, прозрачность и масштабирование фона;
- мобильные выдвижные панели и нижняя навигация;
- страницы, текст, изображения, таблицы, источники, цитаты, хронология и карточки;
- дублирование/удаление объектов, undo/redo, автосохранение в localStorage;
- предпросмотр и печать/экспорт через браузер.

## Ограничения
Это клиентский прототип. PDF формируется через диалог печати браузера. Данные остаются в localStorage текущего браузера; большие фоновые изображения могут занять много места. Таблицы и некоторые сложные блоки пока имеют базовые функции.
